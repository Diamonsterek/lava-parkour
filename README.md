# lava-parkour

Gra stworzona w pełni w czystym HTML, JavaScript i CSS. Kod źródłowy jest publicznie dostępny dla każdego, kto chce zobaczyć, jak gra działa od środka lub stworzyć własną modyfikację.

## Jak uruchomić grę?
1. Pobierz pliki tego repozytorium (kliknij przycisk **Code** -> **Download ZIP** i rozpakuj archiwum).
2. Kliknij w plik `index.html`, aby otworzyć go w dowolnej przeglądarce internetowej.
3. Gra uruchomi się natychmiast, bez konieczności instalacji czegokolwiek.
# Można też zagrać w grę na https://lava-parkour.netlify.app/
