# lava-parkour

Gra stworzona w pełni w czystym HTML, JavaScript i CSS. Kod źródłowy jest publicznie dostępny dla każdego, kto chce zobaczyć, jak gra działa od środka lub stworzyć własną modyfikację.

## Jak uruchomić grę na komputerze?
1. Pobierz pliki tego repozytorium (kliknij zielony przycisk **Code** -> **Download ZIP** i rozpakuj archiwum).
2. Kliknij dwukrotnie plik `index.html`, aby otworzyć go w dowolnej przeglądarce internetowej (np. Chrome, Firefox, Edge).
3. Gra uruchomi się natychmiast, bez konieczności instalacji czegokolwiek.
